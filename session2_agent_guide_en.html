Session 2 · AI Agent Step-by-Step Guide ~ 45–60 min

Give Your Bot
a Brain

From a parrot that echoes, to an assistant that thinks — wire up a LangChain agent on Gemini, give it conversation memory, and plug it into the webhook.

What you'll achieve

In Session 1 your bot just echoed the customer's text. By the end of this session it will understand and answer using a Large Language Model (Gemini), and remember the conversation per customer — so a follow-up like "what about cats?" makes sense in context.

This guide is code-focused. You'll create three new files (prompts.py, memory.py, agent.py), wire two existing ones (main.py, webhook.py), and test without Facebook using a small CLI script.

Before you open this guide

You must have finished Session 1: the echo bot replies on Messenger, your .venv works, and your .env already holds the Facebook tokens. If "hello" doesn't echo back yet, go finish the Session 1 setup guide first.

02
Write the system prompt
app/prompts.py — the bot's personality & rules
~ 5 min

What to do

The system prompt is the most powerful knob you have. Put it in app/prompts.py as a plain string so you can iterate and re-test quickly.

SYSTEM_PROMPT = """You are a friendly customer service assistant for a small business
on Facebook Messenger. Reply in the same language the customer writes in.

Rules you must always follow:
- NEVER invent specific facts. Do not make up prices, opening hours, phone
  numbers, addresses, promotions, services, or policies. If unsure, do NOT guess.
- When you don't have verified information, say honestly that you'll check with
  the team, and offer to note the customer's question or contact for follow-up.
- NEVER reveal internal logic. Do not mention tools, databases, IDs, spreadsheets,
  or that you are "saving" anything. Just respond like a helpful staff member.
- Keep replies short and easy to read on a phone screen, and stay polite."""
Why the "never invent" rule?

In Session 2 the agent has no data source yet, so if you ask "what are your prices?" it will happily make up a plausible answer (a hallucination). The rule tells it to defer instead of guessing. The real fix — answering from your data — arrives in Session 3 with the FAQ tool.

Verify

python -c "from app.prompts import SYSTEM_PROMPT; print(len(SYSTEM_PROMPT))" prints a number > 0 with no import error.

03
Add conversation memory
app/memory.py — remember each customer's chat
~ 5 min

What to do

Memory is a plain dictionary in RAM, keyed by the customer's Facebook PSID. It's wiped on restart — that's intentional for this capstone (persistent storage is out of scope).

from langchain_core.chat_history import InMemoryChatMessageHistory

# user_id (Facebook PSID) -> that one conversation's history.
_histories: dict[str, InMemoryChatMessageHistory] = {}


def get_history(user_id: str) -> InMemoryChatMessageHistory:
    if user_id not in _histories:
        _histories[user_id] = InMemoryChatMessageHistory()
    return _histories[user_id]


def clear_history(user_id: str) -> None:
    _histories.pop(user_id, None)
Verify

No import error: python -c "from app.memory import get_history; print(get_history('u1'))"

04
Build the agent
app/agent.py — create_agent + the reply() helper
~ 12 min

What to do

This is the core file. build_agent() creates the agent once and caches it in a module-level singleton. reply() is the single function the webhook calls for every message.

import logging

from langchain.agents import create_agent
from langchain_core.messages import HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI

from app.config import settings
from app.memory import get_history
from app.prompts import SYSTEM_PROMPT

logger = logging.getLogger(__name__)
_agent = None  # singleton, set once in build_agent()


def build_agent():
    global _agent

    if settings.llm_provider == "gemini":
        llm = ChatGoogleGenerativeAI(
            model="gemini-2.5-flash",
            google_api_key=settings.google_api_key,
        )
    elif settings.llm_provider == "openai":
        from langchain_openai import ChatOpenAI
        llm = ChatOpenAI(model="gpt-4o-mini", api_key=settings.openai_api_key)
    else:
        raise ValueError(f"Unknown LLM_PROVIDER: {settings.llm_provider}")

    # Session 3-4: add tools=[search_faq, save_to_sheet] to the call below
    _agent = create_agent(llm, tools=[], system_prompt=SYSTEM_PROMPT)
    logger.info("Agent built (provider=%s).", settings.llm_provider)
    return _agent


async def reply(user_id: str, message: str) -> str:
    history = get_history(user_id)
    result = await _agent.ainvoke(
        {"messages": history.messages + [HumanMessage(content=message)]}
    )
    reply_text = result["messages"][-1].content

    history.add_user_message(message)
    history.add_ai_message(reply_text)
    return reply_text
Watch out — LangChain 1.x API (not the old tutorials!)

Most tutorials (and older docs) import AgentExecutor and create_tool_calling_agent. Those were removed in LangChain 1.0 — importing them throws ImportError: cannot import name 'AgentExecutor'. In 1.x there is one factory: create_agent. You pass the system prompt directly (no manual ChatPromptTemplate), invoke with {"messages": [...]}, and read result["messages"][-1].content.

Why model = gemini-2.5-flash?

On some new keys, gemini-2.0-flash has zero free-tier quota and returns 429 RESOURCE_EXHAUSTED. gemini-2.5-flash works on the free tier — use it as the default.

Verify

No syntax error: python -c "import app.agent" imports cleanly. (We run the real call in Step 07.)

05
Build the agent at startup
app/main.py — one shared agent via lifespan
~ 5 min

What to do

Building the agent creates an LLM client — slow to do per message. Build it once when the server starts, using FastAPI's lifespan.

from contextlib import asynccontextmanager

from fastapi import FastAPI

from app.agent import build_agent
# ... your existing imports (settings, webhook_router, logging) ...


@asynccontextmanager
async def lifespan(app: FastAPI):
    build_agent()      # build the agent ONCE when the server starts
    yield              # app runs here; code after yield runs on shutdown

app = FastAPI(title="Fanpage Chatbot Capstone", lifespan=lifespan)

Then delete the old # TODO (Session 2): build ONE shared agent… comment.

Verify

Start the server and watch the log:

The line Agent built (provider=gemini). means Step 05 is correct.

06
Swap echo for the agent
app/webhook.py — call reply() instead of echoing
~ 4 min

What to do

Add the import at the top of app/webhook.py:

from app.agent import reply

Then replace the Session 1 echo block inside the message loop:

# --- Session 1: echo ---           # DELETE these two lines
# reply_text = message_text

# --- Session 2: let the agent generate the reply. ---
reply_text = await reply(sender_id, message_text)

await send_message(sender_id, reply_text)
Watch out — call send_message exactly ONCE

If you accidentally leave two await send_message(...) lines, the bot replies twice to every message. Keep a single send. (reply() is async, so it needs await — which works because receive_message is already async.)

Verify

No syntax error: python -c "import app.webhook" imports cleanly.

07
Test locally, then live
scripts/test_locally.py — no Facebook needed
~ 8 min

Create the test script

Put this in scripts/test_locally.py. It lets you talk to the agent straight from the terminal — no ngrok, no Messenger.

import asyncio, os, sys

# make `import app` work no matter where you launch from
sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

# Windows consoles default to cp1252 and choke on non-ASCII — force UTF-8
try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass

from app.agent import build_agent, reply

USER = "local-test-user"  # fixed id so history persists across turns


async def main():
    build_agent()
    args = sys.argv[1:]
    if args:
        print("Bot:", await reply(USER, " ".join(args)))
    else:
        print("Type a message (or 'quit'):")
        while True:
            msg = input("You: ").strip()
            if msg.lower() in {"quit", "exit", "q"}:
                break
            if msg:
                print("Bot:", await reply(USER, msg), "\n")


if __name__ == "__main__":
    asyncio.run(main())

Run it

# one-shot
python scripts/test_locally.py "what time do you open?"

# interactive — best for testing memory across turns
python scripts/test_locally.py

Then test live on Messenger

Make sure uvicorn + ngrok are running (Session 1 setup), then message your fanpage as the admin. The bot should answer intelligently and remember context — no longer just echo.

UnicodeEncodeError: 'charmap' codec can't encode…

That's the Windows console (cp1252), not your code. The sys.stdout.reconfigure("utf-8") line in the script fixes it. On Messenger this never happens — it only affects terminal printing.

Verify

Local test prints a real sentence (not the input echoed). On Messenger, a follow-up question is answered in context. The server log shows Message from … then Sent reply to … exactly once.

Troubleshooting

common errors

These are the snags students hit most in Session 2:

SymptomCommon causeFix
ImportError: cannot import name 'AgentExecutor' Using old LangChain 0.x API on LangChain 1.x Use from langchain.agents import create_agent (see Step 04)
429 RESOURCE_EXHAUSTED (limit: 0) gemini-2.0-flash has no free quota on your key Switch the model to gemini-2.5-flash
Bot replies twice to every message Two send_message() calls in webhook.py Keep exactly one await send_message(...)
UnicodeEncodeError 'charmap' in terminal Windows console is cp1252, not UTF-8 Add sys.stdout.reconfigure("utf-8") (in the test script)
google_api_key is empty / auth fails .env in wrong folder, or server not restarted Put .env in project root; restart uvicorn after edits
AttributeError: 'NoneType' has no 'ainvoke' build_agent() never ran — _agent is None Wire lifespan in main.py (Step 05)
Bot confidently makes up hours / prices No FAQ data source yet (expected in Session 2) Harden the prompt now; real fix is the FAQ tool in Session 3
