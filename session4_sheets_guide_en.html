From an expert that only talks, to an assistant that does — let the bot collect a customer's booking and write it straight into a Google Sheet.

What you'll achieve

Your bot can already answer from real data. Now it takes action: when a customer wants to book, it gathers their name, phone, service, and preferred time, then saves a row to Google Sheets — your live bookings list. This is the final capability: Act.

The new piece is a save_booking tool, authenticated by a Google service account, writing into a sheet you own.

01
Create a service account
Google Cloud → APIs, service account, JSON key
~ 15 min

What to do

  1. Open console.cloud.google.com → create or pick a project (e.g. petsalon-bot).
  2. APIs & Services → Library → enable Google Sheets API AND Google Drive API.
  3. IAM & Admin → Service Accounts → Create service account → name it (e.g. sheets-writer) → Create and continue → skip roles → Done.
  4. Click the account → Keys → Add key → Create new key → JSON → a .json file downloads.
  5. Make a credentials/ folder in the project; save the file as credentials/service-account.json.
  6. Copy the account's email (looks like sheets-writer@PROJECT.iam.gserviceaccount.com) — you need it next.
Watch out
  • Enable both APIs — Sheets to read/write, Drive so gspread can open files.
  • Skip project-level roles; you'll grant access per-sheet (safer).
  • The JSON is a secret key — never commit it. Add credentials/ to .gitignore.
Verify

python -c "import json; d=json.load(open('credentials/service-account.json')); print(d['client_email'])" prints the service account email.

Pitfall #9 — the #1 cause of 403 errors

If you forget to share the sheet with the service account email, every write fails with 403 PermissionError. The robot can only touch sheets you've explicitly shared with it.

Verify

03
Write the booking tool
app/tools/sheets.py — append a row
~ 12 min
"""Save a customer's booking into Google Sheets."""
from datetime import datetime

import gspread
from langchain_core.tools import tool
from app.config import settings

# Connect ONCE at import; reuse the worksheet on every call.
_worksheet = (
    gspread.service_account(filename=settings.google_sheets_credentials_path)
    .open_by_key(settings.google_sheets_id)
    .sheet1
)


@tool
def save_booking(name: str, phone: str, service: str,
                 preferred_time: str, notes: str = "") -> str:
    """Save a customer's grooming booking to the salon's records.
    Call this ONLY after you have the customer's name, phone, the service,
    and their preferred date/time.

    Args:
        name: customer's full name
        phone: customer's phone number
        service: the grooming service requested
        preferred_time: preferred date and/or time
        notes: any extra details (breed, size, special requests)
    """
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    _worksheet.append_row([timestamp, name, phone, service, preferred_time, notes])
    return f"Booking saved for {name} ({service}, {preferred_time})."
Key points
  • Column order in append_row must match your header row exactly.
  • The docstring's "Call this ONLY after…" stops the agent saving half-empty bookings.
  • The return value is for the agent, not the customer — the prompt keeps "saving" hidden.
Verify

python -c "from app.tools.sheets import save_booking; print(save_booking.invoke({'name':'Test','phone':'012','service':'bath','preferred_time':'Sat 10am'}))" adds a row to your sheet (delete the test row after).

04
Wire tool + tune prompt
agent.py + prompts.py — teach it to book
~ 10 min

1 · Add the tool in app/agent.py

from app.tools.sheets import save_booking
# ...
_agent = create_agent(llm, tools=[search_faq, save_booking], system_prompt=SYSTEM_PROMPT)

2 · Add booking guidance to SYSTEM_PROMPT (prompts.py)

# add this block to your system prompt:
Taking a booking:
- When the customer wants to book or leave their details, collect their name,
  phone number, the service, and their preferred date/time. Ask for missing
  details naturally, a couple at a time - don't interrogate.
- Only record the booking once you have name, phone, service, AND preferred time.
- After recording it, warmly confirm the team will reach out to finalize.
  Do NOT promise an exact confirmed slot, and never mention saving anything.
Why "only once you have all four"?

Without this rule the agent may call save_booking with blanks. The prompt makes it gather everything first, then act — and the docstring backs it up.
